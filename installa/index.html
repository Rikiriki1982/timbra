Attiva una nuova ditta

Questa pagina prepara i pezzi da copiare per collegare un nuovo cliente a Timbra. Non salva nulla e non invia nulla: tutto resta in questa pagina.

1. Dati del cliente

Prima crea il progetto Supabase del cliente (vedi la guida). Poi copia qui Project URL e chiave anon da Supabase → Project Settings → API.

2. SQL per le notifiche

Dopo aver incollato ed eseguito supabase/setup.sql, incolla anche questo nell'SQL Editor del cliente e premi Run. Contiene una chiave privata: non mandarla a nessuno e non salvarla nel codice.

Apri l'SQL Editor del cliente

3. Riga da aggiungere a config.js

Su GitHub apri config.js, matita ✏️, incolla questa riga sotto quella di lumia e salva (Commit changes).

4. Link personale del cliente

È l'indirizzo che userà il cliente. Mettilo anche in Supabase → Authentication → URL Configuration: in Site URL e in Redirect URLs.
